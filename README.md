# ⚡ ElectroTarifa

Buscador y comparador de precios de materiales eléctricos en tiempo real entre múltiples proveedores mayoristas y distribuidores de Argentina (**Paternal SRL**, **Jalux**, **Electrocity**, **Electro Tucumán** y **Adma Distribuidora**).

👉 **Entrá a la web:** **[https://electrotarifa.eugenioazurmendi.com.ar](https://electrotarifa.eugenioazurmendi.com.ar)**

---

## ✨ Qué podés hacer

- **Buscar y comparar precios** al instante entre más de 16.000 artículos (con precio final con IVA y neto discriminado).
- **Armar múltiples presupuestos / carritos**, renombrarlos y ver subtotales por proveedor y total general.
- **Copiar pedidos para WhatsApp o Email** filtrados por proveedor, **con o sin precios** (listo para mandar al cliente o pedir cotización al proveedor).
- **Exportar a Excel (CSV)** agrupado por proveedor, con precios o como lista de materiales.
- **Crear tu cuenta gratis** para guardar tus presupuestos y acceder desde cualquier dispositivo.
